description: "根据规范或一组工单实现一项工作。"
disable-model-invocation: true
---

实现用户在规范或工单中描述的工作。

项目已规定 tracker 且本任务有可认领项时，按其约定认领；Seedmux 工单本身不要求另建外部 Issue。没有 tracker 约定时直接推进已授权工作，不把初始化 tracker 变成前置条件。工单关闭由项目的合并流程触发，本技能不附带手动关闭操作。

实现前读取 spec 或工单的验收合同，按验收编号交付实际证据；尚未完成的独立审查或用户路径验收不得以单元测试通过代替。

优先通过现有公共接口与测试入口验证需求。需要先复现缺陷或明确行为时使用 /tdd；不为常规实现额外安排测试边界确认。

按改动运行最窄的受影响检查；只有项目要求、依赖影响或验证缺口支持时扩大范围。不因步骤结束重复跑已通过且输入未变化的检查。

完成点由本次请求与项目规则决定。已授权提交、推送或部署时继续到相应交付完成；用户只要实现或补丁时不附带发布。遇阻塞先完成独立可推进的工作，再说明具体缺口。

提交必须只含本次差异：`git commit -m <msg> -- <你的路径>`；同文件混有他人修改时先隔离自己的补丁，按路径提交本身不能区分文件内归属。审查修复沿用原任务的交付范围与授权，验证受修复影响的行为。
